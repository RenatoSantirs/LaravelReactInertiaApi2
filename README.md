
##Descripción del Proyecto

Este proyecto es una aplicación web Fullstack desarrollada con Laravel, React e Inertia.js, orientada a la gestión de datos mediante interfaces web y APIs REST, con control de acceso por roles y permisos.

La aplicación implementa un CRUD completo para distintos módulos (Contactos, Alimentos, Streams, Usuarios, etc.), combinando vistas renderizadas con Inertia y endpoints API para consumo externo.
